# AliExpress Home Assistant Apps

Home Assistant App repository for AliExpress automation.

## Included App

### AliExpress Coins Bot v0.1.2

Uses a persistent Chromium profile to perform the browser Daily check-in without reproducing AliExpress MTOP security tokens manually.

v0.1.2 adds a lightweight Ingress dashboard for routine use. The slower noVNC browser is now used only when AliExpress login needs renewal.
